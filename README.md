# Plainly

**A Simple, Personal Health Tracker.**

Plainly is a personal health and wellness tracking dashboard designed to help you keep track of everyday habits and health-related information. Log water intake, sleep, exercise, meals, mood, and other personal metrics through one clean and modern interface.

## Features

- Personal daily overview dashboard
- Water intake tracking
- Sleep logging and sleep duration tracking
- Exercise and activity tracking
- Weight tracking
- Mood and energy check-ins
- Meal logging and organization
- Custom habits and daily goals
- History of previous entries
- Calendar for viewing logged activity
- Trends and progress tracking
- Customizable settings and appearance
- Data export and import using JSON and CSV
- Responsive mobile-friendly design
- Simple and easy-to-use interface

## Technologies

- HTML5
- CSS3
- JavaScript
- Browser local storage

## Run Locally

1. Clone or download this repository.
2. Open `index.html` in your browser.
3. No installation or build process is required.

## Live Website

Add your GitHub Pages website URL here once deployed.

## Deploy with GitHub Pages

1. Open this repository's **Settings**.
2. Select **Pages** in the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and the `/(root)` folder.
5. Click **Save**.
6. Wait for GitHub Pages to finish deploying.

The homepage must be named `index.html` and placed in the repository root.

## Updating the Website

Edit `index.html` and commit your changes to the `main` branch. GitHub Pages will publish the updated website automatically.

## Privacy & Disclaimer

Plainly is designed for personal health and wellness tracking. Your entries are stored locally in your browser using local storage. You can export your information to create backups.

Plainly is not a medical service and does not provide medical advice, diagnoses, or treatment recommendations. Consult a qualified healthcare professional for medical concerns.
